AP Macroeconomics — Course Materials Specification

The source of truth for producing Macroeconomics course documents. It records the structures and criteria settled while building the Microeconomics materials, and the adaptations Macro requires.

Anyone — or any agent — working on Macro documents should read this first and follow it rather than improvising a format. It is registered as the /macro-course skill so it loads automatically, and it is readable on its own as a written brief.

4. Structure of each document

4.1 Teaching notes — eight sections

The /module-notes skill already encodes this. Sections: where it sits in the course · terms with a CED anchor · terms whose home is a later unit · terms with no anchor or required elements the module omits · using the AP Review item by item · corrections to make in class · what this module does not give you · suggested allocation · student glossary.

4.2 Terms reference (teacher) — the eight fields

FieldRule
DefinitionVerbatim from Krugman where he defines it, marked otherwise
CED anchorEK code + CED page — or an explicit statement that there is none
Where taughtKrugman book page
Explanation2–4 paragraphs: what it means, why it exists, where students go wrong
Common errorBlockquote callout, one specific mistake
ExamplesThree. One from the text, one numeric where the concept supports it, one illustrative
FigureWherever the numbers can be plotted
RelationshipsTyped links, each with its inverse recorded on the other term

Ordered by dependency, not alphabetically; alphabetical index at the end. Three tiers: Core (assessable in this unit), Preview (assessable in a later unit), Context (no anchor in either course). Entries marked ★ are required by the CED but absent from Krugman and written from scratch.

Relationship types: builds on / prerequisite for · contrasts with (symmetric) · illustrates / illustrated by · component of / has component · measured by · shifts / shifted by.

4.3 Student guide — same spine, different register

Take out: every EK code, every CED page reference, the tier vocabulary, teacher's notes about rubrics, pacing, and all meta-commentary about the textbook's shortcomings.

Translate rather than delete: a missing term becomes "this is not in your textbook — learn it from here"; an unassessed term becomes ○ Background; a rubric mismatch becomes a plain instruction.

Add: ★ / ○ markers, a How to use this guide routine, Check yourself — two questions per entry with a full answer key at the back — a one-page summary, and a closing "things to get right" list.

Write in the second person, in shorter sentences, with Watch out in place of Common error.

4.4 Test — content validity plus Bloom

  • Content-validity blueprint at the top: a table mapping every question to its concept entry, the

terms tested, and its Bloom level. Every entry in the module must appear at least once, weighted by course importance.

  • Scenario-based items only. No item answerable by recalling a definition.
  • Bloom levels: application, analysis, synthesis. Roughly 1 : 3 : 1.75. State the actual counts.
  • Five options A–E per item.
  • Every distractor encodes a documented student error, not filler.
  • Solutions explain all five options — ✓ for the key with its reasoning, ✗ for each wrong one with

why it is wrong. A distractor that reaches the right conclusion by faulty reasoning must be called out as such.

  • Diagnostic table at the end mapping missed questions to the entry to revise.
  • Teacher's notes: content validity, how Bloom levels were operationalised, distractor design, and

the actual answer distribution.

  • Items on unassessed terms go in a separate, clearly flagged section with its own score.

4.5 Unit audit

Check every EK in the unit against the modules normally assigned. Classify: fully covered, partial (idea present, CED framing or a required case missing), absent. Then three tiers — absent from the whole book · absent from these modules but present elsewhere in Krugman · present in substance but missing the framing. Close with a prioritised remediation list and a before/after coverage table.

5. Non-negotiable criteria

These are the rules that made the Micro documents trustworthy. They apply unchanged.

  1. Verify by search, not recall. Any claim that the textbook does or does not contain something

needs a full-text search with the count stated. Several Micro findings turn on a term having zero occurrences. Never assert absence without checking.

  1. Quote EK statements verbatim from ../_extracts/ced_macro.txt. The exact wording is usually the

finding.

  1. Check every number programmatically before it goes in a document — table arithmetic, answer

keys, tallies, Bloom counts, answer distributions. Stated figures have been wrong here more than once and only computation caught it.

  1. Cite by EK code with its CED page, never by Enduring-Understanding code across courses. They

collide: MKT-1 is gains from trade in Macro but scarcity in Micro; MKT-2 is supply and demand in Macro but comparative advantage in Micro; the PPC is MOD-1 in Macro and MKT-1 in Micro. MEA exists only in Macro.

  1. Distinguish "absent from this module" from "absent from the book." Most gaps are the former.
  2. Every relationship link needs its inverse on the other term. Check it programmatically before

shipping.

  1. Say plainly when a module is well aligned. Not every module has problems. Do not manufacture

concerns to fill a section.

6. Figures

Generated by a script, never drawn by hand, so figures and tables cannot drift apart. Macro figures go in AP Macroeconomics/figures/make_figures.py, built on the same Fig class as the Micro one (copy it) with the m0N_ naming convention.

  • Stdlib-only SVG. No matplotlib on this machine. SVG stays crisp, converts cleanly to DOCX/PDF,

and needs no runtime.

  • Escape <, > and & in all text. Macro captions are full of "AD shifts right" and

"SRAS < LRAS"; a raw < produces a silently unrenderable file. The Fig.esc() helper does this.

  • Label both axes and every curve. Skill 4.A is graded on it, and Macro is far more

graph-intensive than Micro.

  • Captions do not wrap — supply each line separately via Fig.caption(), under ~80 characters.
  • Validate every file as XML after generating.

Macro needs far more figures than Micro. Expect per unit:

UnitFigures likely needed
2Circular flow · business cycle · price index / inflation calculation
3AD–AS in short run and long run · multiplier · recessionary and inflationary gaps · long-run self-adjustment · fiscal policy shifts
4Money market · money creation · loanable funds · nominal vs. real interest rates
5Phillips curve short and long run · crowding out · growth via LRAS shift
6Foreign exchange market · balance of payments · capital-flow effects

The AD–AS diagram recurs across Units 3, 5 and 6. Build one parameterised generator for it rather than five near-duplicates.

8. Macro-specific hazards

Things that did not arise in Micro and will here.

Vocabulary now runs the other way. In Micro, Krugman's unemployment and recession had to be retrained to the CED's underutilised resources. In Macro those words are correct and examinable — unemployment is Topic 2.3, business cycles Topic 2.7. Do not carry the Micro correction across. Where Micro documents warn students off a term, the Macro documents may need to switch it back on, and the student guides should say so explicitly for anyone taking both courses.

Krugman's macro sections predate the current framework. Modules 30–36 (Section 6) and 37–40 (Section 7) both feed Macro Unit 5, and Module 16 (Income and Expenditure) develops the multiplier at greater length than Topic 3.2 requires. Expect surplus as often as gaps — the opposite of the Micro problem — and mark surplus material as background rather than cutting it silently.

The MEA family has no Micro precedent. Nothing built for Micro carries over to it. Read those EKs especially carefully; measurement topics are where verbatim wording matters most, because the CED is precise about what counts in GDP, which unemployment is which, and how a price index is built.

Macro is calculation-heavy. GDP, CPI, real versus nominal, multipliers, the money multiplier, real interest rates. Every one is an arithmetic procedure a test can assess at application level, so the numeric example in each terms entry matters more here than it did in Micro.

Unit weights are far more uneven than Micro's. Units 3, 4 and 5 together are 55–80% of the exam; Unit 1 is 5–10%. Weight both teaching time and test items accordingly, and do not give Unit 1 the same treatment Micro Unit 1 received.

9. Order of work

  1. Start at Module 10, not Module 1. Units 1–2 are the shared Micro material.
  2. Per module: teaching notes → terms reference → student guide → test.
  3. Per unit: the gap analysis, once all its modules are done.
  4. Build figures as each module needs them, adding to the unit's generator script.
  5. Update ../CLAUDE.md when a new convention is settled, and this file when a criterion changes.

Suggested first block — Unit 2, Modules 10–15. It is the smallest self-contained unit, it introduces the MEA family, and it is calculation-heavy enough to exercise the numeric-example and Bloom-level machinery before the harder AD–AS units.
